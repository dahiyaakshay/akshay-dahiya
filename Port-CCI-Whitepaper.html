Competitive Content Intelligence for AI Retrievability_

Abstract

This paper documents pre-build validation research for a Competitive Content Intelligence (CCI) module planned as a feature addition to AI Spider, a proprietary website crawler and AI retrievability audit platform. Before committing to building the module, this research was conducted to answer two questions: Is structured content gap analysis a valid signal for predicting and improving AI citation likelihood? Which class of language model performs reliably enough to power this analysis at scale?

The research involved designing a structured 6-dimension analysis prompt, selecting a controlled test set of five competing AI visibility tools, running the prompt across four language models of varying scale and capability, and scoring outputs against a manually derived ground truth.

Research Conclusion

Structured content gap analysis is a valid and actionable signal for AI retrievability improvement. Large frontier models (Claude Sonnet 4.6, ChatGPT GPT-5.5, Gemini 3.5 Flash) perform reliably on this task. Models below the 7B parameter threshold fail at multi-source role tracking and produce unreliable gap attribution. The CCI module will be built using cloud LLM APIs with user-supplied keys.

1. Background and Research Motivation

The shift from keyword-based search to AI-generated answers has created a new visibility problem for brands and local businesses. In traditional SEO, ranking was largely a function of authority signals, backlinks, and keyword coverage. In generative search, a page must also satisfy a different criterion: it must contain the information an AI model expects to see in order to cite it as a source.

This creates a gap that existing SEO tools do not adequately address. Most crawlers and audit platforms measure technical health, keyword coverage, and backlink profiles. None of them measure content completeness relative to what AI models actually cite.

"A page can rank on page one for a target keyword and still be completely invisible in AI-generated answers - not because of technical issues, but because it is missing the specific entities, topics, and terminology that competing pages contain."

AI Spider performs technical AI retrievability auditing. The Competitive Content Intelligence module is a planned addition that would extend AI Spider into the content layer: identifying precisely what information a page is missing relative to its competitive set, and surfacing that as actionable recommendations.

Before building this module, two questions needed validation:

  • Q1 - Is the premise valid? Does structured content gap analysis between a target page and competitors surface meaningful differences that affect AI citation likelihood?
  • Q2 - Which model is right for this task? Do all LLMs perform adequately, or is there a meaningful capability threshold? Can a smaller local model preserve offline functionality?

2. Research Methodology

2.1 The 6-Dimension Analysis Framework

The CCI framework analyses one target URL against competitor URLs across six structured dimensions. Each dimension surfaces a specific type of content gap known to affect AI retrievability.

DIM 01

Information Gain

Unique value the target provides that competitors lack

DIM 02

Entity Gap

Named entities competitors mention that the target omits

DIM 03

Topic Gap

Subject areas covered by competitors but absent from target

DIM 04

Phrase Gap

Industry terminology competitors use that the target lacks

DIM 05

Coverage Score

Percentage of competitor topics addressed by the target

DIM 06

Recommendations

Prioritised content additions ranked by likely impact

Figure 1. Six analytical dimensions of the CCI framework. All dimensions derived purely from provided page content - no external knowledge used by the model.

2.2 Test Set Selection

Five pages from the AI visibility and GEO tools vertical were selected. All cover overlapping topics but from distinct companies. This vertical was chosen because the researcher has deep domain knowledge, enabling accurate manual ground-truth assessment.

  • Target: Semrush AI Visibility Toolkit - product knowledge base page. Marketing-focused, data-rich but narrow in GEO vocabulary.
  • C1 - Peec AI: AI search analytics. Strong on metrics framing (visibility, position, sentiment). MCP integration.
  • C2 - Rankshift: Covers ChatGPT, Perplexity, Claude, Gemini, Mistral, Llama. AI crawler log monitoring. UI-based (not API) response capture.
  • C3 - Promptwatch: Entity Tracker, agentic shopping data, publish-to-citation timeline, content creation features.
  • C4 - OtterlyAI: 30,000+ users, Gartner recognition, Microsoft Copilot tracking, free GEO tools and marketplace ecosystem.

2.4 Prompt Design

A single standardised prompt was designed containing the full extracted text of all five pages, a precise task description, and a strict output format specifying all six analytical dimensions with required sub-fields. All models received the identical prompt with no model-specific modifications. The prompt explicitly instructed models to use only the provided content and no external knowledge - ensuring outputs reflected genuine content gap reasoning rather than model memorisation of the target companies.

The full prompt structure is reproduced below with page content omitted for brevity.

Prompt Template v1.0 · All models identical
Page content omitted

// SYSTEM ROLE

You are a Competitive Content Intelligence engine. Your task is to analyze one TARGET page against four COMPETITOR pages and produce a structured content gap report.

Do not use any external knowledge. Base your entire analysis ONLY on the text provided below.

// INPUT STRUCTURE

## TARGET PAGE
**URL:** [target URL]
**Tool:** [tool name]

**Extracted Content:**
[Full extracted page text — navigation, footer, and boilerplate removed]

---

## COMPETITOR 1
**URL:** [competitor URL]
**Tool:** [tool name]

**Extracted Content:**
[Full extracted page text]

... repeated for COMPETITOR 2, 3, 4

// TASK INSTRUCTION

## YOUR TASK

Analyze the TARGET page content against ALL FOUR COMPETITOR pages and produce the following structured report. Use ONLY the content provided above.

// REQUIRED OUTPUT FORMAT — 6 sections, strict

**1. INFORMATION GAIN ANALYSIS**
List unique information present on the TARGET page that none of the competitors mention.
- Unique sentences / concepts: [list]
- Unique entities: [list]
- Unique phrases: [list]
- Information Gain Score: [0-100]

**2. ENTITY GAP ANALYSIS**
List entities (brands, tools, platforms, companies) mentioned by competitors but ABSENT from the target.
- Missing entities: [list]
- Entities present on target: [list]
- Entity overlap %: [number]

**3. TOPIC GAP ANALYSIS**
List topics covered by competitors but NOT covered by the target page.
- Missing topics: [list]
- Topics covered by target: [list]
- Topic overlap %: [number]

**4. PHRASE GAP ANALYSIS**
List important phrases and terminology used by competitors but absent from the target.
- Missing phrases: [list]
- Unique phrases on target: [list]
- Phrase overlap score: [0-100]

**5. COVERAGE SCORE**
Measure how comprehensively the target covers concepts discussed across all competitor pages.
- Total unique topics across all competitor pages: [number]
- Topics covered by target page: [number]
- Coverage Score: [percentage]
- Missing coverage areas: [list]

**6. RECOMMENDATIONS**
Provide a prioritised list of specific improvements based on the gaps identified above.
- Priority 1 (High Impact): [list]
- Priority 2 (Medium Impact): [list]
- Priority 3 (Lower Impact): [list]
Respond only with the structured report above. Do not add commentary, disclaimers, or explanations outside the report format.

Figure 2. Full prompt template used across all four models. Colour coding: green = role constraint, blue = input blocks, amber = task instruction, purple = output format, red = strict enforcement. Page content replaced with italicised placeholders.

Key Prompt Design Decisions

  • Self-contained content

    All five pages were embedded inline rather than referenced by URL. This eliminated network dependency and ensured every model reasoned from identical input, making outputs directly comparable.

  • Strict format enforcement

    The final instruction ("Respond only with the structured report above") was critical. Without it, smaller models appended commentary and caveats that broke downstream parsing and inflated token usage.

  • No external knowledge

    The explicit prohibition on external knowledge was the most consequential design decision. Without it, models supplemented gaps with their training data - producing confident-sounding but unverifiable additions not attributable to the competitor set.

  • Six dimensions, not one

    Early prototypes used a single "find the gaps" instruction. Splitting into six named dimensions dramatically improved output consistency and reduced hallucination rate across all models tested.

4. Key Findings

F1

The premise is validated

All three frontier models produced coherent, accurate, actionable content gap reports from the same prompt. The methodology reliably surfaces entity, topic, and phrase gaps that a subject-matter expert independently confirmed as real and relevant to AI citation likelihood.

F2

3B models fail at multi-source reasoning

Qwen2.5 3B exhibited critical role confusion - attributing competitor content to the target page - invalidating its entire output. This is not a prompt engineering failure. It is a fundamental reasoning capacity limitation at 3B scale when tracking 5 distinct content sources simultaneously.

F3

Claude: depth. ChatGPT: breadth.

Claude produced fewer but more precise gaps (14 topics vs ChatGPT's 37), with significantly higher recommendation specificity - identifying conversion friction, buyer personas, and vocabulary alignment that ChatGPT missed or listed generically.

F4

Minimum viable threshold is 7B+

A locally-hosted model powering the CCI module would need at least 7B parameters to handle multi-source role tracking reliably. The module will use cloud APIs with user-supplied keys rather than bundled local inference.

"The most practically significant finding is not which model scored highest - it is that the 3B local model failed in the specific way most dangerous for a production feature: silently producing plausible-looking but inverted output, with no error signal."

5. Implications for AI Spider

  • 01

    CCI module will use cloud API with user-supplied key

    Local model inference is not viable at any parameter size currently practical for desktop deployment. The module will integrate via OpenAI, Anthropic, or Google API endpoints - keeping AI Spider dependency-free while enabling the feature for users who want it.

  • 02

    Analysis scoped to URL level, not site level

    URL-level comparison produces better signal quality, lower token cost, and more actionable recommendations. Models performed best when given focused, well-scoped content rather than broad site summaries.

  • 03

    Entity gap is the highest-value dimension for AI retrievability

    Entities are primary citation triggers in AI search. A page that lacks the entities an AI model associates with a topic will not be cited regardless of its authority or technical health - making entity gap the most actionable output of the CCI analysis.

  • 04

    Vocabulary alignment is underserved by current SEO tooling

    The phrase gap dimension revealed pages that were technically comprehensive but used outdated terminology. The target page used "AI search" exclusively, missing the dominant category term "GEO" used by all four competitors. AI models trained on current content are sensitive to this vocabulary mismatch.

  • 05

    One structured prompt replaces hours of manual audit work

    The benchmark confirms that a single well-structured prompt reliably surfaces gaps that would take a human analyst several hours to compile manually. This makes the CCI module a high-leverage addition to AI Spider's existing deterministic audit capabilities.

6. Next Steps

  • 6.1 Module build - AI Spider CCI tab: Standalone tab within AI Spider, independent from the core crawl. Accepts target URL plus up to 4 competitor URLs. Outputs all six analytical dimensions in a structured results dashboard.
  • 6.2 Multi-vertical prompt testing: Additional testing planned across law, healthcare, insurance, and construction verticals to validate prompt robustness across different content types and entity vocabularies.
  • 6.3 Longitudinal citation tracking: Following CCI-informed content updates, AI citation rates will be tracked across ChatGPT, Claude, Gemini, and Perplexity using RankScan to measure whether closing identified gaps correlates with measurable citation improvement.
  • 6.4 7B+ local model re-evaluation: Once Llama 3.1 8B or Qwen2.5 7B are tested on the same prompt, a minimum viable local model recommendation will be published as an addendum to this paper.

Note on Sources

All five URLs used in the benchmark test were publicly accessible pages fetched in May 2025. Page content was extracted by the researcher and included verbatim in the analysis prompt. No model-external knowledge was solicited or used in scoring. Ground truth was compiled manually before running any model tests and was not modified after viewing outputs. Models tested: Claude Sonnet 4.6 (Anthropic), ChatGPT GPT-5.5 (OpenAI), Gemini 3.5 Flash (Google), Qwen2.5-3B-Instruct (Alibaba, via LM Studio v0.3). All tests conducted May-June 2025.
